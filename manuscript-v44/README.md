# Manuscript and formal correspondence

This directory contains the current paper, its bibliography, and the mapping
from manuscript statements to checked Lean declarations. The public inspector
uses this PDF and source.

The correspondence review covers all 66 formal statements and eight
construction entries. The 50 proof bodies and technical construction text are
unchanged from the accepted proof release. One statement has equivalent English
wording about square tables; the reviewed change is recorded explicitly.

The Lean proof code remains pinned to commit
`fb9e87da52d95ba56e20b4ebb5fb4c8217f93a65`. This manuscript update reuses that
checked code; it does not claim a new compilation. Cited source reductions
remain explicit hypotheses. `SOURCE_LOCK.json` binds the current manuscript,
PDF and correspondence receipt.
