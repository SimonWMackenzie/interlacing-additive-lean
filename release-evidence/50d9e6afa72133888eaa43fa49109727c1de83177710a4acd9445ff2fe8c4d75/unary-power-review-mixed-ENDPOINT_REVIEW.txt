   actual graph construction and the literal deterministic request builder.

   original sparse formula. No bound of gap(N) by a fixed polynomial in N
   is inserted.
2. The actual table's size is bounded by declaredSize, and its entries exceed
   the accuracy cutoff eventually. Those obligations and error nonnegativity
   are discharged from the source theorems and ordinary estimator accuracy.
   They are not final theorem assumptions or completed-decider premises.
3. Small sparse inputs are sent through the existing physically implemented
   finite router. The routed formula remains sparse, is sufficiently large,
   and has exactly the original formula's satisfiability. The actual gap
   program and estimator run on that same routed formula and request.
4. The returned FairBitAlgorithm records a real all-raw-input carrier printer
   and one fixed finite caller, with a run for every tape of its printed
   length. totalTime pays carrier printing, one unit per fair bit, linear
   input/tape framing, and every caller transition.
5. The original formula, not the routed large replacement, controls the
   eventual runtime bound. Once the original input is large, routing is the
   identity; the bound is c*S(N,gap(N))^d in its original variable count.
6. The final existence quantifiers return one algorithm for all sparse
   formulas. Its correctness and runtime refer to that same algorithm.
   Error is at most 1/3 and runtime is eventually S^O(1).
7. LargerBound enlarges the source constant before choosing the estimator or
   schedule. Monotonicity transfers the strict error-size condition from
   the larger S to the actual source bound; runtime transfers back upward.
