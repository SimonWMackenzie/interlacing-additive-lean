# Crosscutting construction checks

These eight nodes are explicit preservation checks inherited from the previous
checked companion, not additional unnamed theorems invented in the manuscript.
The v42 map records a `derived_from` list of current exact-source statement IDs
for each node. A check is accepted only when every listed source statement is
accepted, and it carries the union of their exact declaration and independent
review evidence. No candidate-only link is promoted by this derivation.

The original rational-law and physical-constructor checks use the actual
generic fixed-D CodeD machine, its original input-byte polynomial bound and
the attached semantic owners for filtering zeros, retaining duplicate ordinal
labels, normalization, support, bounded-wise marginals and rational temporary
sizes. The machine's output equals the constructive indexed list; an existence
statement for a small support is not substituted for physical execution.

The conditioning check combines the general weighted moment, original-event
conditioning theorem, arbitrary-law nested flattening, retained representatives,
fixed-event pair projections, both suffix branches, generic heterogeneous paired
law, and actual seven-call construction. It explicitly distinguishes original
independence from the possibly dependent law after retaining an arbitrary event.

The graph and complete-encoding checks stay pending until the standalone
generated amplifier, every-admissible-scale deterministic reduction and all-level
sampler claims have accepted providers. This prevents an already checked final
fixed-gap consumer from silently being used as a proof of a broader standalone
source interface. The eventual exact source providers must determine the actual
graph context, seven operands, weighted state, dimensions, threshold and output.

The complexity-model check combines the current closed fixed-gap, deterministic
ETH and randomized sparse-ETH headline endpoints with their model definitions.
The algorithms and original-variable clocks are part of those endpoint proofs;
the distinct external hardness hypotheses remain separate. The alternating
check includes the actual literal-CNF source/table compiler and the starter and
output convention comparisons. The explicit source record and language identity
are not asserted as constructed locally.

The eighth node is `external_input`: cited source-record fidelity and the named
complexity assumptions are explicit boundaries, never Lean completion claims.
The full exact-source compilation, axiom audit, source/PDF identity, independent
whole-map review and publication gate are separate evidence. Treating them as
separate avoids the circular requirement that a final map both contain and be
hashed by its own publication gate. The final gate must bind the frozen map.
